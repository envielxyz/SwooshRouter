# Changelog

All notable changes to Swoosh Router are documented here.

## [1.0.0] - 2026-09-07

### Highlights

- One OpenAI-, Anthropic-, Gemini-, and Ollama-compatible HTTP gateway.
- Dashboard for providers, accounts, models, routing, combos, proxies, usage,
  quota, CLI tools, chat, settings, and logs.
- API key, OAuth, device-code, access-token, refresh-token, cookie, and custom
  provider connection flows.
- Model discovery, custom models, thinking controls, fallback, retry, and
  provider-aware request translation.
- SQLite persistence with migrations, backup/restore, pagination, and bounded
  loading for large account collections.
- Automatic runtime-secret generation, dashboard login protection, masked
  credentials, and graceful shutdown.
- USD/IDR cost display, responsive desktop/tablet/mobile UI, profile photo
  crop and compression, and browser-tested navigation.
- Global Bun CLI, Docker image, Compose setup, and standalone binaries for
  Linux, macOS, and Windows.
