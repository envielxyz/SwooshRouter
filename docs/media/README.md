# Swoosh Router media

Keep public showcase media here so the repository stays organized:

- `screenshots/` — reviewed dashboard screenshots in optimized WebP format.
- `video/` — ignored local source videos; sanitized demos belong in GitHub Release assets.

Current screenshot names:

```text
dashboard.webp
providers.webp
provider-models.webp
usage.webp
settings-preferences.webp
```

Use descriptive names for additional screens. Do not include real API keys,
access tokens, refresh tokens, tunnel URLs, private account names, or other
sensitive data in any media file. Review every frame and audio track before
uploading a video as a public release asset.
